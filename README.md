# Kingsley Chinda portfolio

Responsive portfolio built with Vite and vanilla HTML, CSS, and JavaScript.

## Development

```sh
npm ci
npm run dev -- --port 5173
```

## Production

```sh
npm run build
npm run preview -- --port 5173
```

The résumé is served from `public/kingsley-chinda-resume.pdf`. Project visuals are illustrative, not screenshots of the original projects. Email links open the visitor’s email client. Inter fonts are served locally from `public/fonts`, with sans-serif fallbacks. The design uses a black canvas, luminous red-to-white lettering, and responsive project panels inspired by midu.design.
